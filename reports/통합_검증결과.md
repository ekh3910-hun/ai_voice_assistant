## 2. 통합 기능
| 구분 | 통합 내용 | 검증 |
|---|---|---|
| TC-01 음성 입력 | WAV·MP3 입력, 모노·16kHz 전처리 | 생성 WAV 및 MP3 실제 디코딩 통과 |
| TC-02 STT | 빈 전사 차단, 입력 오류 안내, 이전 전사문 제거 | 모델 대역 및 화면 처리 테스트 통과 |
| TC-03 핵심 AI | 9개 의도, 일 단위·한글 숫자 날짜, 날짜별 수정, 일괄 처리, 최근 메모 | 실제 저장 분류 모델 및 실행 대역 테스트 통과 |
| TC-04 TTS | 일반·실행 중 이벤트 루프 합성, 빈 문장 차단 | API 대역 테스트 통과 |
| TC-05 DB | 제목·내용 일치, 일괄 처리 트랜잭션, 이력 ID 중복 제거 | SQL 호출 및 트랜잭션 예외 전달 검증 통과 |
| TC-06 잘못된 파일 | 비정상 WAV 및 입력형 거절 | 경고·복구 테스트 통과 |
| TC-07 빈/무음 | 무음·공백 차단, 잘못된 날짜 및 불확실 명령 보류 | 작업 실행 차단 테스트 통과 |
| TC-08 API/DB 장애 | 기존 화면 상태 보존, 이력 저장 실패 안내·세션 보존 | 장애 주입 테스트 통과 |

추가 사항:
- DB 미연결 시 가짜 메모·할 일·처리 이력을 표시하지 않음.
- 메모·할 일 페이지 진입 시 DB 새로 조회. 음성 작업 성공 시 DB 결과 재동기화.
- 처리 이력 전체 삭제는 확인 체크 후 실행. DB 실패 시 세션 기록 유지.
- 저장된 모델 평가표는 즉시 표시하고, 재학습은 버튼으로만 실행. 재학습 후 모델 캐시 초기화.
- 기존 `app1_b.py` 실행 명령을 `app.py`로 연결하는 호환 진입점 추가.
- 학습 데이터 및 모델은 개인 저장소의 기존 확장 버전 유지. 성능 우위는 별도 동등 조건 평가 필요.
